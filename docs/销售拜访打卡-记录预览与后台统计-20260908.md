# 销售打卡：记录预览、选店与后台统计

## 用户验收范围

2026-09-08用户反馈：选择门店列表空间不足；已保存录音时长未在记录中显示；记录与明细照片只显示占位；暂不提供详情补充证据入口。随后追加管理员按考勤打卡情况筛选统计、中文规范Excel导出，并授权完成后部署。

## 实现

- 手机选店使用同一表单字段的全高选择页，搜索固定顶部、结果独立滚动；选择后返回，取消保留原门店；取消同时终止防抖与旧查询。输入仅内部档案，按钮/回车才刷新GPS并请求地图。
- 个人历史照片以真实photos/photoIds判断；复用同一租户/记录/对象/SHA旧缩略图，缺图按需受限生成，保留失败重试和原图入口。停止为同一旧原件重复建图任务，媒体与AI分别调度。
- 已保存客户端音频文件时长可直接显示并明确来源；服务端已解析时长优先。录音中断的计时不会伪造为实际音频时长。历史缺时长且不可解析的文件仍明确未知。
- 隐藏记录明细整个补充证据功能；原提交时尚在上传的媒体恢复能力继续工作。
- 后台增加日期快捷选项、全筛选汇总和每日销售表，支持分页与一键查对应明细。统计取完整过滤结果，不从当前页相加。没有排班规则，不推断旷工、迟到或应出勤天数。
- 真正xlsx下载，两个中文工作表：每日销售汇总、打卡明细。表头、条件说明、冻结窗格、筛选、交替底色、中文业务值、列宽；中国时间写为Excel日期数值，显示yyyy-mm-dd hh:mm:ss。手机号与潜在公式文本保持字符串。超过20000条拒绝并提示缩小范围；导出单槽、轻量字段与照片计数控制内存。

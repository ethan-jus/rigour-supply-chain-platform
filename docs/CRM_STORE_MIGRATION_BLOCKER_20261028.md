## 原因与修正

V1 及冻结 B24 已有 `crm_store`，使用 BINARY(16) 主键，contact/address/sales_assignment 等旧外键引用它。原新功能 V28 再次创建同名且结构不兼容的表，09:53:03 在第一条建表语句失败。此次用户 11:28 的启动日志依然为 `Detected failed migration to version 28`：失败记录会阻止修正脚本重新执行。

新功能主档改为 `crm_store_master`，新 identity/ownership/summary 外键及公海查询写入同步调整。V28 只新增 8 张功能表；原 `crm_store`、客户、主体、来源身份及其关联完全保留。不进行名称/POI 自动合并，不切换旧业务入口，不双写两份主档。V1～V27 及 B24 保持原样。V28 成功后即冻结，后续变更另增版本。

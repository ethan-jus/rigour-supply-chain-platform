# 订货宝客户排除与发货自动同步暂停验收

## 规则

- 客户来源的 `clientAreaName` 去除首尾空白后等于“散客”时，不新建或改写客户档案；原始来源快照仍保留。零售客户类型本身不作为排除条件。
- 明确人工排除的来源绑定记录为 `EXCLUDED / CUSTOMER_MANUALLY_EXCLUDED`。来源名称、地区、业务员后续改变也不会重新创建客户。
- 已经关联的散客保留原客户 ID 和历史关联；本次只逻辑删除用户指定的客户档案。
- 排除记录不进入客户待核对和重试队列，对外登记为 `IGNORED`，不再计为映射冲突。
- 业务定时链和不指定范围的通用订单同步，仅同步销售订单、收款、付款，保留删除核对和凭证补齐；不再拉取发货、调拨或重试发货积压。历史单据不清理，不将未解决的发货记录伪装成已完成。

# 销售拜访打卡：搜索、定位、多图与录音改进

本轮代码已在隔离工作树完成并通过本地验证。用户于2026-09-08明确授权提交、合并dev与部署；发布前版本为385c7a2，最终运行版本、迁移结果和备份以本轮发布记录为准。原始开发目录中的未提交工作未修改。

本地预览：http://127.0.0.1:8774/sales-checkin/ 。使用虚构账号、门店和记录；上传只保存到本地模拟服务内存，重启清空。这里的测试不调用真实高德、不写生产、不录制电脑真实麦克风。

## 销售交互

- 输入门店名称或地址，350ms 防抖仅查询内部档案，单字可查，自动展示候选。
- 点击搜索或按回车才重新采集 GPS，随后并行查内部档案与高德 POI。只按稳定门店标识去重，同名分店保留；按服务端计算距离升序，未知距离放最后。结果区域可上下滑动。
- 已建档门店直接选择；地图门店选择后进入资料补全，保留地图候选签名关联的建档 ID。地图失败仍能选择内部档案；内部失败也保留成功的地图结果。
- 业务城市默认已验证销售的城市，包括总部；允许修改。业务城市用于归属统计，GPS 和附近门店按设备实际位置获取，身份和租户校验不放开。
- 登录进入自动定位，显示解析地址及醒目的重新定位按钮；不展示首页精度、备注和额外确认选项。显式搜索和第一次提交重新采样，定位失败保留真实可获得证据，不挡正常打卡。
- 页面恢复不会打断已进行的定位或搜索，30秒内已取得位置不重复采样。逆地理按实际坐标缓存：成功5分钟、失败15秒；相同坐标并发去重。缓存不替换设备原始坐标、精度和时间。
- 支持1–9张现场照片，继续拍照、相册多选、逐张缩略图和删除。12MP JPEG 顺序生成至多384px预览，及时释放解码资源；超过16MP且不适合安全预览的文件保留原件和占位提示。
- 至少一张照片确认后完成打卡，其余照片、录音和截图独立补传。文件保持稳定ID，丢响应先查回执；明确413/415拒绝不盲目重试。草稿可删，已提交24小时内可追加，原始已收照片不可由销售改删。
- 个人记录保留日期、范围和排序；明细展示全部照片。后台列表和详情展示每张缩略图，照片较多可横向浏览，原图/下载按该照片UUID鉴权。

## 录音与真实边界

页面切后台不再主动stop。支持时使用 AudioSession 和前台 Wake Lock，监听系统中断、暂停和麦克风结束；已知暂停不计入有效录制时长。录音分块使用现有IndexedDB仓库和512MiB总配额串行保存，完整终止的录音幂等恢复，未完整封装的分块仅作为待检查恢复件，不自动伪装成正常可播放录音。

网页不能承诺 iOS、微信、荣耀浏览器切应用或锁屏后持续录音。本地模拟和WebKit引擎验证不能替代具体设备真机测试。需要销售在原设备测试切应用、锁屏、接电话后返回；若业务必须保证长时间后台录音，需另行评估具备系统后台录音能力的原生客户端。

已删除录音同意和隐私强制勾选；浏览器自身的麦克风许可仍由系统处理。新记录 privacyAccepted=false，历史已记录值保留。privacyNoticeVersion是界面告知版本，不能解释成用户已明确同意；本轮未改变原有后台转写规则。

## 后续发布检查

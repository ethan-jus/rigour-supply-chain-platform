# 货拉拉企业详情字段留存与展示对照

版本：V3.5　日期：2026-11-12　性质：需求评审的开发对照附件，不是业务页面。

依据[官方企业详情 e-order-detail](https://open.huolala.cn/#/doc/api?menu=9&type=2&id=9)页面返回参数表，共109个参数行（含容器、重复名称的不同嵌套字段，不是109个数据库列）。字段名按官方原文核对；下表按业务归类说明保留与展示。实际完整路径和数据类型必须以真实回执结构校验，不能仅按同名字段拼成一层。

## 留存约束

- 实际返回的业务数据整体保存为来源回执版本，按完整路径保留未知扩展字段；核心身份、时间、费用与关联字段提取供查询。接口没返回的不能宣称已落库；空、未提供、取数失败分别记录。
- 图片和文件单独转存自有COS，保存来源订单、站点、费用项目、资料类别、源文件引用、归档结果及历史版本；平台资源不可人工覆盖，失败可重试。
- 不因一次部分回执缺字段清掉先前已获取的历史资料。已确认成本及确认归属快照独立保护；原账单／已付／退款／优惠不能多次累加成成本。
- 官方限制：近一年订单可查；司机完成72小时后不再返回司机信息；goods_imgs等资源需商务权限。pay_status和tax_value已停止维护，留原值但不用于计算当前付款状态。
- 官方示例若有参数表之外的字段，仍保留原始业务数据，不猜测其成本含义。授权Token和密钥不写入业务回执展示。

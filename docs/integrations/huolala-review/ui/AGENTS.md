# Prototype Instructions

Run the local server yourself and open the preview in the browser available to this environment. Do not give the user server-start instructions when you can run it.

Before making substantial visual changes, use the Product Design plugin's `get-context` skill when the visual source is unclear or no longer matches the current goal. When the user gives durable prototype-specific design feedback, preferences, or decisions, record them in `AGENTS.md`.

When implementing from a selected generated mock, treat that image as the source of truth for layout, component anatomy, density, spacing, color, typography, visible content, and hierarchy.

Build app UI in `src/`. Keep `.openai/hosting.json`, `worker/index.js`, `scripts/prepare-sites-build.mjs`, and `tests/sites-worker.test.mjs` intact so the same local prototype can be handed to Sites. Before a Sites handoff, run `npm run build` and `npm run test:sites`; the build must leave `dist/client/index.html`, `dist/server/index.js`, and `dist/.openai/hosting.json`.

## 2026-11-12 V3.1 最新业务方向（覆盖此前销售配送顺序）

- 已完成货拉拉订单自动同步后直接进入物流运输记录，不等销售单选择才建记录，不设候选池作为额外业务主入口。
- 销售订单列表／详情增加选择物流，选择已有运输记录；只建立关系，自动带销售业务员及部门，不新增第二笔费用。支持同车多单、单订单多次配送。
- 手工物流在运输记录新增；每笔必须至少上传一份图片或文件凭证才可保存，编辑不能移除全部凭证。订货宝来源人工补录费用也需费用凭证。
- 费用按运输记录确认金额去重计算；销售关系用于归属分摊。平台账单只读，重复同步不重计、不能覆盖已确认成本。
- 订货宝真实销售发货关系可自动带入；与货拉拉／手工同一运输时复用来源，不重复计费。
- 本轮仅文档和独立原型，用户确认后才改正式代码。


## 2026-11-12 V3.2 非货拉拉快捷录入

- 销售订单选择顺丰、极兔等非货拉拉公司或自营配送时，必须在当前弹窗提供显眼的手工录入入口，不能只提示业务到运输页另行新增。
- 共用运输新增表单，自动带原销售单、方式、公司及收货信息；凭证必填。一次保存运输及当前销售关系，不新增重复费用。
- 保留选择已有运输防重复，以及运输页独立新增入口；货拉拉仍只关联已完成同步记录。


## 2026-11-12 V3.3 字典及选择边界

- 公司、配送方式、付款状态等选项沿用现有数据字典；原型通过独立字典示例模块演示，不把公司列表散落在业务组件中。
- 当前只有货拉拉可选已完成同步记录；其他公司与自营进入手工录入，订货宝已明确关联的物流直接展示，不要求重录。此规则覆盖V3.2非货拉拉可选已有列表的描述。
- 销售入口新增与关联后的运输类型固定销售订单配送；不能将已有调拨／其他用途强改为销售。仍只改评审文档和原型。

- 新增／编辑表单参考用户16:10截图：费用信息（含选填分项）在发货信息之前；发货仓库、实际发货方、联系人、电话、地址统一呈现，仓库可带入并允许按实际更正；最终统一进入运输记录列表，销售侧只追加关系。


## 2026-11-12 V3.4 附件能力不得丢失

- 销售物流流程调整必须保留回单元数据、费用凭证和按站点／阶段区分的装卸货照片。详情明确展开分类，不以单一附件空态代替原能力。
- 平台资料只读；已获取可预览下载，失败显示原因并单独重试；重试及重复同步不改变运输费用和确认快照。手工凭证继续必填和预览下载。
- 仅更新评审文档和原型；示意文件明确不是平台真实凭证，不能把原型下载当作COS真实验收。


## 2026-11-12 V3.5 统一表单与完整校验

- 新增／编辑／查看及销售入口统一基本信息、关联销售单、费用、发货、收货路线、凭证影像、备注；费用在发货之前，平台补充信息靠后。
- 红星代表保存必填；金额未知可暂存，确认前必填；分项行添加后项目与金额必填；0费用备注必填。手工所有记录至少1份有效凭证，不强制同时提供装货照、卸货照和回单。
- 必填清单、页面标识、字段级错误与确认校验对应；平台只读字段缺失按来源状态处理，不要求业务手抄。官方字段保留与展示边界单独对照，不能用原型当真实落库或COS验收。

- 本版订货宝示例同时在销售详情和运输详情展示来源销售单、发货单、仓库、公司、快递单号及收发货快照，缺费用不置零；人工补费用仍需凭证，重复同步保持同一记录和人工费用。

# 商家库与私海作业 DEV 验收 · 2026-10-30

## 本轮范围

商家库是授权范围内的统一门店总账，包含公海、私海和历史合作门店。公海/私海表示当前归属，合作历史是独立维度，不复制门店资料。本轮区分商家库管理与私海作业，复用已有认领、归属、拜访和采集服务。未新增数据库表或迁移，未关联或迁移旧客户档案，未改造新门店直接开单。

## 已实现

- 商家库增加归属池、档案状态筛选，默认可以查看授权范围内正常、停用、停业及合并档案；展示当前归属、档案状态及修改信息，操作入口为维护。
- 我的客户/团队客户增加跟进阶段和保护状态筛选，展示负责人、待首访/持续跟进/合作维护、保护截止、最近有效拜访及公开电话。当前负责人可以退回；团队查看权限不授予代拜访能力。
- 门店详情突出当前归属作业信息和下一步要求。待核验显示暂缓回收，不把到期时间误示为已经丢失归属。
- Sales Vue H5 增加客户与门店 → CRM 私海入口，查询本人私海。开始拜访前重新核实权限及当前归属，检查上班签到，再使用已有定位能力发起 CRM 门店采集，进入已有照片、录音、结果提交、离店工作区。已有未离店采集可继续，网络重试复用请求标识。
- 新筛选复用同一服务端权限及查询条件，作用于列表、计数和地图。只有商家库管理动作能查询非正常档案，认领和业务作业保持正常档案限制。

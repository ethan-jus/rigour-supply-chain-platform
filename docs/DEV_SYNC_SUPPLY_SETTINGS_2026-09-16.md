1. **菜单名称回归**：远程导航的 `DISPLAY_NAME_OVERRIDES` 会覆盖后台自定义名称。合并保留服务端名称和层级，新 HR/拜访页面仍注册并可从菜单管理选择。

3. **BI 数据范围遗漏**：远程新增四个 JDBC 看板仅使用旧城市/员工筛选，不能执行完整角色规则。现与 MyBatis 复用 SQL 数据范围：每条角色条件先求交，再合并角色并应用成员上限，过滤先于关联、统计及分页。客户统计按当前主责；订单统计按冻结归属。
4. **BI 跨领域读库**：HR 和 Sales 新来源改为专用 SERVICE API，导出最少字段、校验租户/游标/完整列集合及版本，BI 原子发布本地镜像。新增客户属性和地区父级字段也纳入 CRM 投影。ACTIVE 请求重验当前人员/部门和业务关联，失败不返回旧的扩大范围。人员来源版本与员工/拜访投影在同一事务内发布，局部业务刷新不能提前消耗人员版本。旧直接读库授权脚本由领域 API 文档取代。
5. **HR 状态冲突**：远程区分 `LEFT=离职` 与 `INACTIVE=停用`；本地员工编辑和应用校验已同步。普通用户强制关联有效 HR 员工的规则保持。
6. **Flyway 编号冲突**：5 个服务的本地迁移与远程历史重号。21 个仅在本地测试、未部署的迁移顺延；远程全部迁移内容逐字节保持。没有执行 repair。

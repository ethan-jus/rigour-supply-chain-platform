# 成本与报销本地验收记录（2026-10-22）

## 适用范围和结论

基于现有 Portal、ERP、Order、HR、IAM、BI 实现修改。当前是连接 DEV 数据的本地运行实例、真实登录页面及代码回归结果；未部署生产。已修复的事项与尚缺环境／角色验证的事项分别记录，不能据此宣称完整上线验收已通过。域服务仍为各自业务数据的唯一写者，BI 通过分析源接口生成只读快照。

业务规则：人力只计已确认月度薪酬，激励包含在提成中；差旅、住宿、打车保留报销；采购和损耗分列，不作为已售商品成本；关联同一原费用的报销不得重复计入；月度租赁按费用所属月统计。未增加审批、财务审核、银行支付或库存估值流程。
